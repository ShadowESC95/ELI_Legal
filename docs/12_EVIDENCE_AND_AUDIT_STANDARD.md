# Evidence and audit standard

Record evidence as the run happens. Minimum lineage for material work: matter ID, run ID, claim ID, source/version ID, source locator, model/tool/prompt/workflow versions, verification type/outcome, human decision, stop/hold/restart events.

Audit integrity does not prove substantive legal correctness. HMAC authenticates the log chain; separate verification establishes source/proposition/current-law correctness.
