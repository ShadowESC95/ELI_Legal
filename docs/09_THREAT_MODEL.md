# Threat model starter

Initial threats: stale/overruled authority; hallucinated citation; correct citation supporting the wrong proposition; hidden prompt injection in matter files; source poisoning; cross-matter leakage; over-broad tools; compromised connector; unauthorised reviewer; audit deletion/truncation; key compromise; automation bias; model/tool drift; silent corpus change; privileged-content leakage.

Each threat should map to a preventive/detective/responsive control and an executable test.
