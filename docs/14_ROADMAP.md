# Roadmap

## Phase 0 — scaffold
Ports/adapters, matter IDs, policy boundaries, fail-closed audit, hard gate types, test harness.

## Phase 1 — matter/evidence foundation
Matter store, RBAC, ingestion, source manifest, claim/evidence graph, deterministic workflow states.

## Phase 2 — legal source layer
Approved connectors, case-law retrieval, citation verification, current-law/treatment checking, jurisdiction/rules packs.

## Phase 3 — analysis layer
Fact/issue/evidence mapping, proposition verification, source-linked drafting, uncertainty representation.

## Phase 4 — assurance
Gold matters, adversarial tests, thresholds, reviewer studies, monitoring, incident/restart exercises.

## Phase 5 — optional ELI v3 integration
Implement ports with v3 inference/DAG/retrieval/document/audit services while retaining the legal capability boundary.
